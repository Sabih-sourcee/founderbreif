WHAT THIS SESSION CHANGED
1. Web voice notes now record the microphone and send the audio to /api/transcribe-voice.
   Before this, the Voice Note sheet pasted a sample sentence and did not transcribe.
2. The local server accepts JSON { audioBase64, mimeType } as well as a file upload.
   JSON body limit is 12mb so a real recording is not rejected.
3. Transcription asks Gemini to return the spoken words. Empty audio is rejected instead of inventing a pitch.
   Transcripts can be up to 1500 characters.
4. The website boots again. LandingScreen and DescribeIdeaScreen are named exports, matching App.tsx.
5. Supabase on the API now reads the names already set on Vercel:
   SUPABASE_URL, VITE_SUPABASE_URL, and SUPABASE_SERVICE_ROLE_KEY.
6. The phone app skips empty recording files before upload.

HOW TO RUN IT LOCALLY
1. git checkout 90-percent-fixed
2. git pull
3. npm install
4. Secrets must live in the PROJECT ROOT file named .env
   The server does not read src/.env. If the key is only in src/.env, copy that file to .env in the repo root, then restart.
   Required name: GEMINI_API_KEY
   Also used: ADMIN_EMAIL, ADMIN_PASSWORD, APP_URL
5. npm run dev
6. Open http://localhost:3000
7. Record -> mic -> speak -> send. Then Generate.
